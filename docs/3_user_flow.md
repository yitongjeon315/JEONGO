# [중국어 학습 웹앱] 사용자 플로우 (User Flow)

본 문서는 서비스의 핵심 시나리오 5종에 대한 사용자 경험 흐름을 도식화하고 상세 단계를 정의하는 사용자 플로우(User Flow) 설계서입니다.

---

## 1. 회원가입, 온보딩 및 배치 테스트 플로우

새로운 사용자가 앱에 진입하여 자신의 수준을 측정하고, 캐릭터를 생성하여 최초로 학습에 안착하기까지의 과정입니다.

```mermaid
graph TD
    A[앱 최초 실행 및 랜딩] --> B{로그인 여부}
    B -- "로그인 안 됨" --> C[소셜 로그인 / 간편 회원가입]
    B -- "로그인 완료" --> G[홈 대시보드 진입]
    C --> D[온보딩: 학습 목적 및 하루 목표 시간 설정]
    D --> E[배치 테스트 / 레벨 테스트 선택]
    E --> F{테스트 진행 여부}
    F -- "진행" --> F1[AI 배치 테스트: 5문항 풀이 및 스피킹 테스트]
    F1 --> F2[결과 분석: 신 HSK 레벨 추천 및 기본 스탯 결정]
    F -- "건너뛰기" --> F3[왕초보 단계 자동 지정 및 기본 스탯 배정]
    F2 --> H[캐릭터 생성 및 클래스 선택]
    F3 --> H
    H --> I[최초 학습 던전 가이드 튜토리얼]
    I --> G
```

### 상세 단계 설명:
1.  **소셜 로그인**: 카카오톡 또는 구글 계정을 통해 3초 만에 회원가입을 완료합니다.
2.  **온보딩 설정**: "취업/이직", "여행", "자기계발" 등 목적과 "하루 15분(보통)", "하루 30분(열공)" 등의 복습 강도를 설정합니다.
3.  **배치 테스트**: AI가 학습자의 발음과 어휘력을 측정하는 5개의 미니 게임을 통해 적절한 난이도의 스테이지(예: HSK 1급 수준, 3급 수준)를 자동으로 제안합니다.
4.  **캐릭터 생성**: 자신의 부캐 역할을 할 학습 파트너 캐릭터의 외형 및 성격 클래스(어휘 집중형, 회화 집중형 등)를 설정합니다.

## 2. 일일 학습 및 망각 곡선 기반 어휘 복습 루프

어휘력을 나타내는 STR 스탯을 올리고, 망각곡선 주기상 복습해야 하는 단어를 몬스터와 매칭하여 해결하는 핵심 학습 루프입니다.

```mermaid
graph TD
    A[홈 화면 진입] --> B[오늘 복습할 단어 수 체크]
    B --> C{복습할 단어가 있는가?}
    C -- "있음 (복습 시급)" --> D[어휘 복습 던전 강제 진입 권장]
    C -- "없음 (클리어 상태)" --> E[새로운 어휘 학습 던전 선택]
    D --> F[퀴즈 시작: 몬스터 체력 바 표시]
    E --> F
    F --> G{퀴즈 정답 여부}
    G -- "정답" --> H[몬스터 피해 입힘 / 기억 강도 상승]
    G -- "오답" --> I[몬스터에게 공격받음 / 오답 큐에 추가]
    H --> J{스테이지 내 모든 단어 완료?}
    I --> J
    J -- "아니오" --> F
    J -- "예" --> K[결산: XP, Gold, 스탯 획득 및 망각 주기 갱신]
    K --> L[홈 화면 복귀 및 스탯 상승 연출]
```

### 상세 단계 설명:
1.  **복습 알림**: 앱 진입 시 `user_vocabulary_progress` 테이블을 조회하여 현재 망각 임계값 이하로 떨어진 단어가 있을 경우 빨간색 "던전 침공" 연출을 띄워 복습을 최우선으로 유도합니다.
2.  **전투형 퀴즈**: 단어가 적힌 카드를 보고 뜻을 맞추거나 한자 획순을 맞출 때마다 몬스터의 HP가 감소합니다.
3.  **기억 강도 반영**: 답변의 정확도와 속도가 우수하면 복습 간격(Interval)이 2배로 늘어나며, 오답인 경우 당일 내 재학습 큐에 들어가 즉시 다시 출제됩니다.

## 3. AI 튜터 상황극 및 섀도잉 세션 플로우

말하기 유창성(DEX) 및 성조 정확성(INT)을 훈련하기 위한 AI 오디오 챗 기반 롤플레이 플로우입니다.

```mermaid
graph TD
    A[AI 튜터 탭 진입] --> B[AI 튜터 및 시나리오 선택]
    B --> C[대화 세션 시작: AI 튜터 선제 음성 발화]
    C --> D[AI 대화 번역 및 실시간 자막 노출]
    D --> E[사용자 차례: 마이크 버튼 활성화]
    E --> F[사용자 음성 입력 및 섀도잉 발화]
    F --> G[실시간 음성 데이터 전송 및 STT/발음 평가 실행]
    G --> H{발음 및 성조 판별}
    H -- "성조/발음 통과 (80점 이상)" --> I[칭찬 연출, AI 답변 이어나감]
    H -- "성조/발음 불합격" --> J[틀린 음절 피치 차트 시각화 및 피드백]
    J --> K{재도전 여부}
    K -- "재도전" --> F
    K -- "넘어가기" --> I
    I --> L{대화 목표 완료?}
    L -- "아니오" --> D
    L -- "예" --> M[세션 리포트: 스피킹 유창성 분석 및 골드 지급]
```

### 상세 단계 설명:
1.  **시나리오 선택**: "카페에서 주문하기"와 같은 일상적 상황을 고르면 AI 튜터가 적합한 표정과 억양으로 말을 겁니다.
2.  **발음 평가**: 사용자의 음성을 녹음하여 Pinyin 단위로 쪼개고, 4성 성조의 정확도를 체크합니다.
3.  **피치 피드백**: "중국어 3성의 끝부분을 더 내리지 못했습니다"와 같은 실시간 교정 피드백과 함께 원어민의 음성 파형과 겹쳐볼 수 있는 비주얼 차트를 표시합니다.

## 4. 길드 가입 및 협동 퀘스트 플로우

유저 간 리텐션을 극대화하기 위한 소셜 협동 및 경쟁 흐름입니다.

```mermaid
graph TD
    A[길드/소셜 탭 진입] --> B{가입된 길드 여부}
    B -- "없음" --> C[길드 추천 리스트 조회 또는 생성]
    C --> D[길드 가입 완료]
    B -- "있음" --> E[길드 로비 입장]
    E --> F[길드 주간 협동 퀘스트 확인]
    F --> G[던전 플레이를 통해 퀘스트 점수 기여]
    G --> H[기여도 및 길드 랭킹 실시간 갱신]
    H --> I{주말 마감 시각 도달}
    I -- "예" --> J[보스 클리어 성공 여부 판정]
    J -- "성공" --> K[대량의 길드 전용 골드 및 스킨 보상 분배]
    J -- "실패" --> L[기본 보상만 획득 및 다음 주 퀘스트 준비]
```

## 5. 현실 보상 교환 플로우

열심히 학습하여 모은 가상 재화(골드)를 현실의 커피 기프티콘이나 편의점 상품권으로 바꾸는 환전 유저 저니입니다.

```mermaid
graph TD
    A[상점 탭 진입] --> B[현실 보상 환전소 메뉴 선택]
    B --> C[보상 아이템 목록 탐색 및 상세 보기]
    C --> D{보유 골드 충분 여부}
    D -- "부족함" --> E[무료 골드 충전소: 광고 시청 또는 추가 어휘 미션 유도]
    D -- "충분함" --> F[교환 신청 버튼 클릭]
    F --> G[본인 확인 및 기프티콘 수신 휴대전화 번호 입력]
    G --> H[결제 처리 및 Supabase DB 골드 차감]
    H --> I[기프티콘 발송 대기 큐 등록 및 푸시 알림 발송]
```
