# [중국어 학습 웹앱] UI 설계 및 디자인 시스템 (UI Design)

본 문서는 서비스의 일관된 시각적 아이덴티티와 프리미엄 유저 경험을 위한 디자인 시스템 토큰 및 핵심 화면들의 UI 구조를 설명하는 UI 설계서입니다.

---

## 1. UI 디자인 컨셉 및 철학

*   **Glassmorphism & Dark Mode**:
    *   깊이감 있는 어두운 백그라운드 위에 블러 가공된 유리 카드를 올려 시각적 밀도와 세련된 공간감을 형성합니다.
    *   다크 모드를 기본 테마로 설정하여 장시간 학습 시 눈의 피로를 최소화하고, 게임 화면 같은 몰입감을 선사합니다.
*   **Micro-interactions (미세 인터랙션)**:
    *   단어 카드를 스와이프할 때의 탄성 효과, 퀴즈 정답 시 불꽃이 튀는 이펙트, 캐릭터 성장 시 스탯이 오르며 발광하는 네온 이펙트 등을 Framer Motion을 통해 유기적으로 구현합니다.

---

## 2. 디자인 시스템 가이드라인 (Design Tokens)

TailwindCSS 및 Vanilla CSS 변수로 설정할 핵심 색상과 스타일 스펙입니다.

### 2.1 Color Palette (HSL 기반)
*   **Background (배경색)**: `hsl(220, 25%, 7%)` - 매우 어두운 차콜 네이비
*   **Glass Card (카드 기본 배경)**: `hsla(220, 20%, 15%, 0.6)` + `backdrop-filter: blur(20px)`
*   **Accent Colors (포인트 네온 컬러)**:
    *   *Neon Green (어휘/안전/STR)*: `hsl(142, 70%, 50%)`
    *   *Neon Cyan (성조/INT/스마트)*: `hsl(180, 80%, 50%)`
    *   *Neon Rose (연속일수/VIT/열정)*: `hsl(340, 80%, 60%)`
    *   *Cyber Yellow (골드/보상/보너스)*: `hsl(48, 95%, 50%)`
*   **Border Color (유리 테두리)**: `hsla(0, 0%, 100%, 0.1)`

### 2.2 Typography (폰트 지정)
*   **영어 및 숫자**: `Outfit`, `Inter` (구글 폰트 적용)
*   **한글 및 중국어(한자)**: `Noto Sans KR` / `Noto Sans SC` (가독성과 자형 밸런스가 뛰어나 한자 획순 식별에 적절)

## 3. 핵심 화면 레이아웃 설계 (Wireframe Specs)

### 3.1 홈 대시보드 (Home Dashboard / RPG 캐릭터 화면)
이 화면은 사용자가 자신의 '부캐' 성장을 한눈에 파악할 수 있는 메인 대시보드입니다.

```
+-------------------------------------------------------------+
| [Profile] 👑 Level 14   ⚡ Streak 45일    🪙 3,450 Gold    |
+-------------------------------------------------------------+
|                                                             |
|           / \         * 장착 스킨: 무림 맹주 복장           |
|          | o o |      * 칭호: 신조협려                      |
|           \ _ /                                             |
|           / | \                                             |
|          /  |  \      [스탯 포인트 분배 가능! +3]            |
|         /   |   \                                           |
|            / \                                              |
|                                                             |
|   💪 STR (어휘) [██████████░░] 84 (레벨업 +)                |
|   ⚡ DEX (유창) [██████░░░░░░] 52 (레벨업 +)                |
|   🧠 INT (성조) [████████░░░░] 68 (레벨업 +)                |
|   ❤️ VIT (연속) [████████████] 99 (Max 스탯)                |
+-------------------------------------------------------------+
|   [⚔️ 오늘 복습할 어휘 12개]       [🗣️ AI 튜터 챗 개시]       |
+-------------------------------------------------------------+
```
*   **구성 요소**:
    *   **헤더**: 유저 레벨, 현재 스트릭, 보유 골드(Gold) 표시.
    *   **캐릭터 모델 뷰어**: PWA 환경에서 자이로스코프 센서를 반영하여 화면을 기울이면 캐릭터 뒤의 네온 후광이 입체적으로 반응하는 3D 또는 인터랙티브 2D 그래픽 배치.
    *   **스탯 인터페이스**: 레벨업을 통해 획득한 자유 포인트를 버튼 클릭으로 각 스탯에 투자할 수 있으며, 투자 시 스펙이 실시간으로 동기화됩니다.

### 3.2 어휘 던전 (Vocabulary Spaced Repetition Card)
전투형 어휘 퀴즈 카드로, 몬스터의 라이프 바가 상단에 노출되는 게임 UI입니다.

```
+-------------------------------------------------------------+
|  [Dungeon: 만리장성 1-3]               Monster HP [████░░░░] |
+-------------------------------------------------------------+
|                                                             |
|                       [ 🇨🇳 苹果 ]                           |
|                       ( píngguǒ )                           |
|                                                             |
|         이 단어의 알맞은 한글 뜻을 선택하십시오.             |
|                                                             |
|        +-------------------------------------------+        |
|        |   [1] 바나나                              |        |
|        +-------------------------------------------+        |
|        |   [2] 사과      (Neon Green Highlight)    |        |
|        +-------------------------------------------+        |
|        |   [3] 오렌지                              |        |
|        +-------------------------------------------+        |
|                                                             |
+-------------------------------------------------------------+
|  [⚡ 힌트 물약: 50G]                       [🧪 스트릭 가드]  |
+-------------------------------------------------------------+
```
*   **인터랙션 피드백**:
    *   정답 선택 시 몬스터 카드가 흔들리며 데미지 수치(-15 HP)가 공중에 둥둥 뜨는 연출 제공.
    *   오답 선택 시 유저 인터페이스 전체가 붉은빛으로 미세하게 진동.

### 3.3 AI 튜터 회화 및 성조 분석기 (AI Pitch Analyzer)
중국어 특유의 높낮이(성조)를 음성 평가 후 시각화해 주는 섀도잉 피드백 UI입니다.

```
+-------------------------------------------------------------+
| [AI Tutor] 릴리 (현지인 친구)                     [종료]     |
+-------------------------------------------------------------+
|  릴리: 你今天吃了什么？(오늘 뭐 먹었어?)                      |
|                                                             |
|  나: 我吃了 汉堡包。(wǒ chī le hànbǎobāo)                   |
+-------------------------------------------------------------+
|  [성조 피치 차트 분석 결과]                                 |
|     High  - - - \ / - - -                                   |
|            \     /                                          |
|             \___/   (한바오바오의 4성 하강이 약함!)         |
|     Low                                                     |
|            [wǒ] [chī] [le] [hàn] [bǎo] [bāo]                |
|             ok   ok   ok  [Bad]  ok   ok                    |
+-------------------------------------------------------------+
|                    [🎙️ 다시 말하기]                          |
+-------------------------------------------------------------+
```
*   **성조 시각화**:
    *   학습자가 발음한 음성 신호의 기본 주파수(F0) 값을 실시간 분석하여 곡선 그래프 형태로 표현합니다.
    *   원어민 가이드라인(반투명 점선)과 유저 발음(실선)을 대조 표기하여, 4성을 똑바로 내리지 못했거나 3성을 덜 꺾은 부위를 실시간 지적합니다.

## 4. Framer Motion 인터랙션 명세 (Animations)

1.  **화면 전환 (Page Transition)**:
    *   Bottom Tab 클릭 시 현재 화면이 좌측으로 페이드 아웃(`opacity: 0, x: -30`)되고 새 화면이 우측에서 부드럽게 밀려 들어옴 (`opacity: 1, x: 0`, `transition: { type: "spring", stiffness: 300, damping: 30 }`).
2.  **몬스터 처치 및 보상 획득 (Dungeon Clear Alert)**:
    *   퀴즈가 완료되면 화면 중앙에 전리품 박스가 등장하고 박스가 둥둥 위아래로 움직임(Y축 Loop 애니메이션).
    *   클릭 시 골드 코인 파티클이 화면 곳곳으로 방사형으로 퍼져나감 (Framer Motion `LayoutGroup` + Dynamic Particles).
