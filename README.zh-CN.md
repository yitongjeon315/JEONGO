# JEONGO

[한국어](README.md)

JEONGO 是一款以移动端体验为核心、将中文学习与 RPG 成长和战斗机制结合起来的学习型 Web 服务。学习者可以在掌握 HSK 词汇与中文句子的同时培养角色，并把每日练习转化为任务、奖励和持续成长。

- JEONGO 服务：<https://www.aina365.com/>
- TOPIK-Edu 服务：<https://www.aina365.com/topic/>

## 项目希望提供的体验

外语学习最重要的是坚持，但单纯背诵往往难以长期保持动力。JEONGO 把答题设计成战斗，把学习记录转化为角色成长，把重复目标组织成每日任务，让学习者能够直观看到自己的进步。

学习成果通过经验值、等级、金币、连续学习天数和成长属性呈现。一次答对所带来的即时反馈，会与长期累积的成长记录连接在同一个游戏世界中。

## 核心学习内容

### 词汇战斗

根据汉字和拼音选择正确的韩语含义。正确答案会转化为攻击，连续答对则会带来更强的战斗反馈。

### 句子组装

按照韩语句子的含义排列中文词块。学习者不仅记忆单词，还能通过实际组合掌握中文语序和句子结构。

### HSK 词汇与生词本

支持从 HSK 1 级到 6 级的分阶段词汇学习。需要再次查看的词语和答错的内容会进入生词本与复习流程。

### AI 导师与成长系统

AI 导师、角色属性、每日任务和学习统计共同构成完整的成长循环。学习者可以同时查看当天目标与长期成果。

## 用户体验

- 优先适配手机屏幕的响应式界面
- 无需登录即可开始的访客学习模式
- 登录用户的学习状态与角色成长记录同步
- 通过学习统计和每日任务保持复习动力
- 用于管理学习资料的管理员内容页面
- 可从 JEONGO 直接进入 TOPIK-Edu 的统一学习入口

## 与 TOPIK-Edu 的关系

JEONGO 仓库中还包含韩语能力考试学习项目 TOPIK-Edu，目录为 `services/topic1`。两个服务共享同一域名，但分别保持独立的学习对象与界面体验。

```text
www.aina365.com/         中文 RPG 学习 JEONGO
www.aina365.com/topic/  韩语 TOPIK 学习 TOPIK-Edu
```

JEONGO 顶部的 TOPIK 入口和 TOPIK 页面中的返回按钮，让学习者可以自然地在两个服务之间切换。

## 服务组成

- 基于 Next.js 与 React 的 JEONGO 学习应用
- 基于免费 SQLite 的用户、会话、学习快照与服务器端金币交易记录
- 基于 Vite 的 TOPIK-Edu 静态学习应用
- 基于 Caddy 的 HTTPS、域名跳转与路径分流
- 使用 Vitest 与 Playwright 验证核心学习流程

## 项目定位

JEONGO 面向从中文入门者到需要反复复习 HSK 高级词汇的学习者，目标是提高学习的持续性与成就感。项目的核心并不是把传统练习册搬到网页上，而是让每一次学习行为都成为角色冒险的一部分。
