# TOPIK-Edu Smart Academy

[简体中文](README.zh-CN.md)

TOPIK-Edu Smart Academy는 TOPIK I(1급) 학습을 세 번의 집중 수업으로 구성한 모바일 대응형 웹서비스입니다. 강의 커리큘럼, 어휘 학습, 읽기·듣기 문제, 복습 게임과 강사용 수업 도구를 하나의 흐름으로 제공합니다.

- TOPIK-Edu 서비스: <https://www.aina365.com/topic/>
- JEONGO 메인: <https://www.aina365.com/>

## 프로젝트 목표

TOPIK을 처음 준비하는 학습자가 시험의 전체 구조를 부담 없이 이해하고, 실제 문제를 풀기 전에 필요한 어휘와 표현을 충분히 익히도록 돕는 것이 목표입니다. 정답 확인에만 집중하지 않고 사전 학습, 실전 연습, 해설과 복습이 순서대로 이어지도록 설계했습니다.

## 3회 완성 커리큘럼

### Session 01 · 기본 인물, 장소, 동작

시험에서 자주 등장하는 사람, 장소와 기본 동작 어휘를 중심으로 TOPIK I 문제 형식에 익숙해집니다.

### Session 02 · 일상생활과 물건 쇼핑

가격, 수량, 장소와 일상 대화에 필요한 표현을 학습하고 읽기·듣기 문제에 적용합니다.

### Session 03 · 시간, 상태, 미래 계획

시간 표현, 상태 묘사와 계획 관련 어휘를 학습하고 전체 내용을 종합적으로 복습합니다.

## 학습 경험

- 이미지와 연상 기호를 활용한 핵심 어휘 카드
- 어휘와 이미지를 연결하는 매칭 게임
- 읽기·듣기 문제 전 사전 지식 학습
- TOPIK I 유형을 참고한 실전 연습과 문항별 해설
- 브라우저 음성 합성을 활용한 듣기와 다시 듣기
- 회차별 진도와 상세 강의 시간표
- 휴대전화에서 카드가 화면을 벗어나지 않는 반응형 구성

## 강사용 수업 도구

- 정답과 지도 정보를 제어하는 강사 모드
- 한 문제씩 크게 보여주는 화면 공유 모드
- 수업 자료 PDF 인쇄와 오프라인 PPT 교안
- 수업 내용을 현장에서 조정할 수 있는 편집 기능
- Google Apps Script 기반 실시간 다국어 번역 수업방

실시간 번역 수업방은 교사가 입력한 한국어를 영어, 중국어 간체, 베트남어와 네팔어로 전달할 수 있도록 구성되어 있습니다. 학생은 자신의 언어를 선택하고 기기에서 번역 문장을 음성으로 들을 수 있습니다.

## 모바일 인터페이스

강의 커리큘럼과 학습 카드는 모바일 화면의 한 열 안에서 자연스럽게 이어집니다. 터치 버튼은 작은 화면에서도 충분한 크기를 유지하며, 표처럼 폭이 필요한 콘텐츠만 내부 가로 스크롤을 사용합니다.

## JEONGO와의 관계

TOPIK-Edu는 독립 GitHub 프로젝트이면서 JEONGO 저장소의 `services/topic1`에도 포함됩니다. 운영 환경에서는 `www.aina365.com/topic/` 경로로 제공되며, 상단의 `JEONGO로 돌아가기` 버튼을 통해 중국어 RPG 학습 서비스로 이동할 수 있습니다.

## 프로젝트 구성

- Vanilla JavaScript 기반 화면과 학습 로직
- Vite 기반 정적 웹 애플리케이션
- 반응형 CSS와 모바일 커리큘럼 카드
- Browser Speech Synthesis 기반 음성 기능
- Google Apps Script `LanguageApp` 기반 번역 수업방
- 이미지, 아이콘과 TOPIK 수업용 PPT 자료

## 콘텐츠 안내

본 서비스의 연습 문항은 TOPIK I PBT의 일반적인 문항 유형을 참고해 자체 제작한 학습 자료입니다. 실제 기출문제를 그대로 제공하는 서비스가 아닙니다.
