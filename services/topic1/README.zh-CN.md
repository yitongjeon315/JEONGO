# TOPIK-Edu Smart Academy

[한국어](README.md)

TOPIK-Edu Smart Academy 是一款面向移动端的韩语能力考试学习 Web 服务，把 TOPIK I（1 级）内容组织成三次集中课程。课程体系、词汇学习、阅读与听力练习、复习游戏以及教师课堂工具被整合在同一条学习流程中。

- TOPIK-Edu 服务：<https://www.aina365.com/topic/>
- JEONGO 主页：<https://www.aina365.com/>

## 项目目标

项目希望帮助第一次准备 TOPIK 的学习者轻松理解考试结构，并在做题之前充分掌握必要的词汇与表达。学习流程不只关注答案，而是依次连接课前知识、实战练习、解析和复习。

## 三次完成课程

### Session 01 · 基本人物、场所与动作

学习考试中常见的人物、地点和基础动作词汇，并熟悉 TOPIK I 的题型。

### Session 02 · 日常生活与购物

学习价格、数量、场所和日常对话表达，并应用到阅读与听力问题中。

### Session 03 · 时间、状态与未来计划

学习时间表达、状态描述和计划相关词汇，最后综合复习全部内容。

## 学习体验

- 使用图片和联想符号的核心词汇卡
- 连接词汇与图片的配对游戏
- 阅读与听力练习前的基础知识学习
- 参考 TOPIK I 类型设计的实战练习与逐题解析
- 使用浏览器语音合成的听力与重复播放
- 每次课程的进度与详细课堂时间表
- 在手机屏幕中不会偏离卡片区域的响应式布局

## 教师课堂工具

- 控制答案与教学信息的教师模式
- 每次显示一道题的屏幕共享模式
- 课堂资料 PDF 打印与离线 PPT 教案
- 可在课堂现场调整内容的编辑功能
- 基于 Google Apps Script 的实时多语言翻译课堂

实时翻译课堂可以把教师输入的韩语传递为英语、简体中文、越南语和尼泊尔语。学生可选择自己的语言，并通过设备语音听取翻译内容。

## 移动端界面

课程卡片与学习内容在手机上以单列方式自然排列。触控按钮保持足够的点击面积，只有表格等确实需要较大宽度的内容才使用内部横向滚动。

## 与 JEONGO 的关系

TOPIK-Edu 既是独立的 GitHub 项目，也包含在 JEONGO 仓库的 `services/topic1` 目录中。线上服务位于 `www.aina365.com/topic/`，用户可通过顶部的“返回 JEONGO”按钮进入中文 RPG 学习服务。

## 项目组成

- 基于 Vanilla JavaScript 的界面与学习逻辑
- 基于 Vite 的静态 Web 应用
- 响应式 CSS 与移动端课程卡片
- 基于 Browser Speech Synthesis 的语音功能
- 基于 Google Apps Script `LanguageApp` 的翻译课堂
- 图片、图标与 TOPIK 课堂 PPT 资料

## 内容说明

本服务的练习题参考 TOPIK I PBT 的常见题型自行制作，并不直接提供真实历年试题。
