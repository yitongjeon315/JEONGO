# BEFORE JEONGO

병음을 처음 배우는 사용자를 위한 독립 입문 앱입니다.

## 학습 흐름

- 성조 DJ 부스: 네 성조를 두 번씩 듣고 직접 따라 말하기
- 성조 버블팝: 12개 듣기 게임, 오답 자동 재등장
- 병음 조립 공장: 핵심 성모·운모 10개 조립
- 첫 단어 스프린트: 생활 단어 12개를 뜻·소리·병음으로 연결
- 성조 리듬런: 성조 변화가 포함된 짧은 표현 8개 듣기

별도의 배치고사 없이 모든 게임을 마치면 JEONGO HSK 1 학습으로 연결됩니다.

```powershell
npm run dev
```

- BEFORE JEONGO: http://localhost:3002/before
- 운영 주소: https://www.aina365.com/before
- 같은 도메인의 JEONGO로 돌아가며, 별도 도메인을 쓸 때만 `NEXT_PUBLIC_JEONGO_URL`을 지정합니다.
